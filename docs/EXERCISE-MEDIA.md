# Imagens dos exercícios

19 imagens originais do pacote `@bryllim/workout-guide@1.0.0` (npm), por Bryl Lim, com obras derivadas de Everkinetic onde indicado. Licença dos arquivos visuais: CC BY-SA 4.0, https://creativecommons.org/licenses/by-sa/4.0/.

Fonte: https://github.com/bryllim/workout-guide e https://github.com/everkinetic/data.

Somente o primeiro quadro de cada exercício foi copiado, sem alterar os pixels. A interface aplica fundo verde para dar contraste aos traços brancos e redimensiona a exibição. A licença está junto aos arquivos em `src/assets/exercises/LICENSE-ASSETS.txt`. Os créditos, links originais por imagem, equipamento ilustrado e hashes SHA-256 estão em `src/data/exercise-media.json`. Atribuição e licença também são acessíveis ao ampliar cada imagem no aplicativo.

As imagens identificam o exercício e o equipamento. Não são vídeo, avaliação de execução nem prescrição individual. Exercícios com variações genéricas indicam explicitamente o modelo ilustrado, como desenvolvimento sentado com halteres e rosca com halteres.

Os 19 arquivos são hospedados com o aplicativo, versionados e incluídos no cache estático da PWA após a atualização. Nenhuma API externa de mídia, chave ou rastreador é necessário.
